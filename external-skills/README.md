# External skills — ICIBINA V5

Este diretório não redistribui código de terceiros. As skills GitHub são baixadas pelo instalador pinado usando `external-skills-lock.json`.

Política:
- UI: UI/UX Pro Max + 21st + React + Motion + accessibility, cada um sob gatilho estreito.
- Backend: skill oficial FastAPI para mecânica atual; arquitetura ICIBINA prevalece.
- Database: Postgres/SQL specialists apenas para tuning/SQL complexo.
- QA: Test Master e Playwright somente quando a tarefa é de testes/QA.
- Security: Security Reviewer apenas em auditoria/milestone/release.
- Observability: skills oficiais Grafana/OTel/k6 somente em instrumentation/performance.
- Clean Code, Software Architect e FastAPI Expert genérico ficam manual/review-only.

Não atualize refs automaticamente. Upgrade de skill é uma mudança de supply chain e deve ser revisada.
