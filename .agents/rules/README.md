# Antigravity rules

O Antigravity 2.0 lê regras do workspace em `.agents/rules/`.

No IDE/Antigravity 2.0, configure `project-core.md` como **Always On**. Mantenha esta regra curta; detalhes especializados ficam em Skills e nos documentos referenciados.

Não duplique documentos inteiros dentro de Rules. Rules servem para invariantes que devem acompanhar qualquer tarefa; Skills servem para workflows acionados apenas quando relevantes.
