Referência visual aprovada para o **Student Immersive**. Serve para calibrar:

- atmosfera premium dark medical/academic;
- integração de fotografia contextual com conteúdo;
- sidebar e hierarchy de aprendizagem;
- hero editorial do aluno;
- right rail de jornada/próxima aula;
- densidade média e cards com conteúdo real;
- uso seletivo de serif em headings;
- profundidade sem neon/glass excessivo.

### Não é fonte de verdade isolada

A imagem contém conteúdo visual/conceitual e não define por si só componentes, textos, dados, acessibilidade, breakpoints ou comportamento. Em caso de divergência:

```text
MASTER.md
→ SURFACES.md / MOTION.md / COMPONENTS.md
→ page override
→ referência visual
```

Não copiar literalmente branding, nomes, métricas ou conteúdo fictício da imagem. Implementação deve usar dados reais/fixtures aprovadas e os tokens oficiais.
