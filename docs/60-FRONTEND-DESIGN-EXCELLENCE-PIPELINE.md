# 60 — Frontend Design Excellence Pipeline — ICIBINA V5.8

Este documento descreve como tirar **o máximo valor útil** de UI/UX Pro Max, 21st.dev e Motion sem degradar consistência, acessibilidade ou contexto do agente.

## Pipeline

```text
Product intent + real data states
        ↓
Surface profile + page override
        ↓
UI/UX Pro Max research / dials
        ↓
Local primitive inventory
        ↓
21st search / explore (if open)
        ↓
21st build or local React build
        ↓
Motion tier decision
        ↓
Interaction implementation
        ↓
21st review
        ↓
UI/UX targeted audit
        ↓
Playwright / axe / visual / reduced motion / perf
        ↓
Task evidence
```

## Regra anti-context-bloat

Cada etapa libera apenas o especialista necessário. Não pré-carregar todas as skills. Documentos extensos são recuperados por necessidade.

## Critério de UI de alto nível

A interface precisa parecer deliberadamente desenhada para ICIBINA, não “um dashboard SaaS com verde”. Isso é provado por:

- surface profile coerente;
- hierarchy ligada ao objetivo da rota;
- conteúdo realista do domínio;
- photography/iconography consistente;
- componentes locais reutilizados;
- motion com motivo explícito;
- QA visual e acessibilidade.

## Student experience

A V5.7 oficializa `Student Immersive` como a linguagem premium da área do aluno. Isso inclui dashboard e player, mas não autoriza dark cinematic no admin/checkout.

## Exit criteria

Nova página/redesign não fecha sem evidence de review visual, responsividade, reduced motion e a11y aplicáveis.
