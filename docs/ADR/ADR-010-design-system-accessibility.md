# ADR-010 — Design System evidence-first + WCAG 2.2 AA

**Status:** Accepted

## Decision
Usar `design-system/integrative-medicine/MASTER.md` como source of truth, Tailwind tokens, shadcn/21st adaptados localmente e WCAG 2.2 AA como baseline.

## Consequences
UI não pode ser “inventada” página a página por agentes. Visual regression + axe entram nos gates de rotas críticas.
